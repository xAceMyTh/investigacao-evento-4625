Evidência 01 - Evento 4625

Foi identificado um evento de falha de autenticação SMB durante a análise do ambiente de laboratório.

O registro indica uma tentativa de acesso utilizando o usuário Thiago, realizado da máquina KALI. A autenticação ocorreu por meio do NTLM, utilizando o Logon Type 3, que está relacionado a acessos realizados pela rede.

Event ID: 4625
Usuário alvo: Thiago
Logon Type: 3
Authentication Package: NTLM
Workstation: KALI
Resultado: Falha de autenticação
